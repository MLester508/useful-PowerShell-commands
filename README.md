# useful-PowerShell-commands

A simple repository for storing and reusing PowerShell scripts you have already created.

## Structure

- `/scripts` - reusable PowerShell scripts

## Current scripts

- `Get-SystemInfo.ps1` - returns quick machine and PowerShell environment details

## Usage

Run any script from the repository root:

```powershell
pwsh ./scripts/Get-SystemInfo.ps1
```
